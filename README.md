# Payroll-Management-System-Python-MySQL
A CLI-based Payroll Management System built with Python and MySQL.
Developed a CLI Payroll Management System using Python and MySQL to automate employee financial tracking and reporting.   
Engineered a relational database schema via mysql.connector to securely store employee designations and salary metrics.   
Designed an interactive, menu-driven interface enabling comprehensive CRUD operations for seamless employee record management.   
Implemented dynamic business logic to automatically compute Gross and Net Salaries based on organizational hierarchies.   
Configured role-specific financial algorithms determining Dearness Allowance (DA) and House Rent Allowance (HRA) percentages.   
Automated income tax deduction calculations tailored to distinct employee designations like Officer and Manager.   
Built a dynamic salary increment module that seamlessly updates base pay and recalculates all dependent allowances.   
Created an automated reporting engine to generate and display formatted, individualized employee salary slips.   
Developed a centralized tabular dashboard to display comprehensive, workforce-wide payroll summaries in real-time.   
Ensured systemic data integrity by triggering automatic metric recalculations whenever basic salary or roles are modified.
